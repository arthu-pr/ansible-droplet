# Install user softwares

Opinionated and personal Softwares to install on a fresh Ubuntu server

## Steps

- zsh, with Prezto
- dotfiles - will install my current dotfiles [repository](https://github.com/arthur-plazanet/dotfiles), and run the sync script
  - Neovim configuration
  - Zsh configuration
  - Zellij configuration
  - etc.
- [Zellij](https://github.com/zellij-org/zellij)
- Neovim from [source](https://github.com/neovim/neovim?tab=readme-ov-file#install-from-source)
